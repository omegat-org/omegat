# Common Recipes

Task-oriented recipes for extending the OmegaT GUI and core, with the concrete
file touch-points. These complement the reference chapters (Core Methods,
Utility functions) by answering "where do I change things to add X?".

## Add a menu item

1. Declare a field in `BaseMainWindowMenu`: `JMenuItem toolsXxxMenuItem;`.
2. Instantiate it in the create block: `toolsXxxMenuItem = createMenuItem("TF_MENU_TOOLS_XXX");`.
3. Add it to its menu: `toolsMenu.add(toolsXxxMenuItem);`.
4. To enable it only while a project is open, add it to the `itemsToSwitchOff` array.
5. Add the action to `MainWindowMenuHandler`: `public void toolsXxxMenuItemActionPerformed() { ... }`.
   It is bound reflectively by matching the field name plus `ActionPerformed`.
6. Add the label to `Bundle.properties`; a `&` marks the mnemonic. An optional
   accelerator goes into `MainMenuShortcuts.properties` (and `.mac.properties`)
   keyed by the field name.

## Localization (`.properties`) conventions

- Bundles are ISO-8859-1 with `\uXXXX` escapes for every non-ASCII character
  (`ü` is `ü`, `…` is `…`, all CJK is escaped). ASCII stays literal,
  including `{0}` placeholders and `&` mnemonics.
- Add a new key to `Bundle.properties`, then a value to each `Bundle_xx.properties`.
  Every key in the base bundle should resolve in each locale.
- Minimize translation work by reusing an existing key whose text already fits,
  rather than minting a new one. Confirmed reusable generics: `BUTTON_CLOSE`,
  `BUTTON_OK`, `ISSUES_TABLE_COLUMN_TYPE` ("Type"),
  `ISSUES_TABLE_COLUMN_ENTRY_NUM` ("Segment"), `ISSUES_TYPE_ALL` ("All").
- Set button text (with mnemonic) via
  `org.openide.awt.Mnemonics.setLocalizedText(button, OStrings.getString(key))`.
- Escape non-ASCII with a native2ascii step or a small script; do not commit raw
  UTF-8 into these files.


## Iterate project segments by scope, then write translations

- All segments: `Core.getProject().getAllEntries()`.
- Current file: match `Core.getEditor().getCurrentFile()` against each
  `IProject.getProjectFiles()` `FileInfo.filePath`, then use `FileInfo.entries`.
- Current filter: keep `getAllEntries()` where
  `Core.getEditor().getFilter().allowed(ste)` (the filter may be null).
- Source/target locale: `getProjectProperties().getSourceLanguage().getLocale()`
  and `getTargetLanguage().getLocale()`.
- Register a translation:
  `Core.getProject().setTranslation(ste, new PrepareTMXEntry(src, tgt), true, externalLinked)`,
  then `Core.getEditor().refreshView(false)`.

  (year plus sequence, e.g. `2026003`), linked from `adr/index.md` under a section.

  "Home page: https://www.omegat.org/" and "This file is part of OmegaT"; this is
  enforced by `svn.CopyrightTest`.
