  Source      com.ibm.icu:icu4j 78.3, the version this build ships.
  Method      RuleBasedNumberFormat.getRuleSetNames() for the NUMBERING_SYSTEM,
              SPELLOUT and ORDINAL formatters of every available language, then
              format(2143) for each rule set.
  Caveat      The default locale is set to the root locale before asking. A
              language without rules of its own otherwise inherits the rules of
              the JVM default language, which makes it look as though Basque,
              say, spelled its numbers in German.
  Omitted     192 languages that have no rules of their own and fall back to the
              root rules, printing digits rather than words.
  Note        The numbering systems in the root locale are script-bound and
              locale-independent; OmegaT's NumeralValueParser reads eleven of
              them, and %spellout-numbering for zh, zh-Hant and ja.
