Zahlensegmente automatisch ausfüllen

Preislisten, Kataloge und Finanzberichte stecken voller Segmente, die nur aus einer Zahl, einem Preis, einem Datum oder einer Uhrzeit bestehen. Tools > Zahlensegmente automatisch umwandeln... füllt sie alle auf einmal aus – so geschrieben, wie es die Zielsprache verlangt.

Das ist mehr als Kopieren: Aus Englisch €1,234.56 wird Deutsch 1.234,56 €, aus 12/31/2026 wird 31.12.2026, aus Chinesisch 第3 wird Englisch 3rd. Auch römische, ideografische, arabisch-indische, Devanagari-, thailändische und vollbreite Zahlzeichen werden gelesen.

Jede Konvertierung wird vor dem Anwenden mit Vorschau und Konfidenzwert angezeigt, und die konvertierten Segmente werden markiert, sodass der Sprung zum nächsten unübersetzten Segment sie überspringt.
