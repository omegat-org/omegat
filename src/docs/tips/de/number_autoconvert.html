Zahlensegmente automatisch ausfüllen

Preislisten, Datenblätter, Kataloge und Finanzberichte stecken voller Segmente, die nur aus einer Zahl, einem Preis, einem Datum oder einer Uhrzeit bestehen. Tools > Zahlensegmente automatisch umwandeln... füllt sie alle auf einmal aus – so geschrieben, wie es die Zielsprache verlangt.

Das ist mehr als Kopieren: Die Zahl wird in der Ausgangssprache gelesen und für die Zielsprache neu geschrieben – in beliebiger Richtung. Zum Beispiel:

  • Englisch €1,234.56 → Deutsch 1.234,56 €
  • Englisch 12/31/2026 → Deutsch 31.12.2026
  • Arabisch ٥٠٪ → Englisch 50%
  • Chinesisch 第3 → Englisch 3rd, und Englisch 1st → Deutsch 1.
  • Schwedisch 3:e → Englisch 3rd

Auch Zahlzeichen vieler Schriftsysteme werden gelesen: das römische MMMCCXIV, das ideografische 三千二百十四, arabisch-indische ٣٢١٤, Devanagari-Ziffern ३२१४, thailändische ๓๒๑๔ und vollbreite ３２１４ werden alle zur schlichten 3214, die die Zielsprache erwartet.

Jede Konvertierung wird vor dem Anwenden mit Vorschau und Konfidenzwert angezeigt, und die konvertierten Segmente werden markiert, sodass der Sprung zum nächsten unübersetzten Segment sie überspringt.
