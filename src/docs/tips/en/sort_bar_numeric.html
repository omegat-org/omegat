Sort segments by numeric value

When you sort by a text-based criterion in the sort bar, the direction selector offers Numeric ascending and Numeric descending next to the plain alphabetical order.

Numeric sorting orders segments by the actual value of the number they contain, so "Step 2" comes before "Step 10" — where a plain alphabetical sort would place "10" before "2".

It recognizes numbers written in many ways: a leading sign, decimals and fractions (for example -5, 1.5, 3/2, ½), and numerals from many writing systems — Western and other decimal digits, Roman numerals (XII), CJK (十二) and further systems supported by ICU, as well as enclosed or circled numbers (⑩).

Because ordinary words such as "mix" or "XL" are valid Roman numerals too, the selector also offers Numeric asc./desc. no-Roman: the same value-based order, but Roman numerals count as plain text. The collapsed sort bar shows this mode as 1↑/1↓ instead of #↑/#↓.

Values are compared exactly, so 1/3 orders correctly against any decimal and very large numbers never overflow. Segments with no recognizable number, or with equal values, fall back to the normal alphabetical order for a stable result.
