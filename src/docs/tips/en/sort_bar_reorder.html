Reorder segments with the sort bar

Above the segment list sits a collapsible Sort bar. Collapsed, it shows a one-line summary such as "Sort: File order (unsorted)"; click the header to expand it.

After "Sort by:" pick a criterion — from order & structure over source text, translation and notes to repetitions and history — plus a direction; "then by:" adds tie-breakers, and criteria can be moved or removed to change priority.

Sorting changes only the display — project and file order stay untouched, and a short warning reminds you that segment numbers are no longer sequential. "File order (unsorted)" restores the original order.
