Reorder segments with the sort bar

The editor has a collapsible Sort bar above the segment list. When it is collapsed it shows a one-line summary such as "Sort: File order (unsorted)"; click the header to expand it.

After "Sort by:" pick a criterion — grouped into Order & structure, Source text, Translation, Notes & comments, Repetitions & tags and History — and a direction. Add "then by:" criteria to break ties, and move or remove criteria to change their priority.

Sorting only changes how the segments are displayed; it does not change your project or the segment order in the files. A short warning reminds you that, while sorted, the segment numbers are no longer sequential.

To return to the original order, choose "File order (unsorted)" again.
