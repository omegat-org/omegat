Projectmappen

Een project van OmegaT bestaat uit een set mappen en bestanden die al uw bronnen voor vertaling bevat. De standaard namen zijn als volgt.

  • source bevat de bronbestanden
  • target is de locatie waar de doelbestanden worden gemaakt
  • glossary bevat de woordenlijsten
  • tm bevat de verwijzings-vertaalgeheugens
  • dictionary bevat de verwijzings-woordenboeken
glossary.txt is the project writable glossary.
